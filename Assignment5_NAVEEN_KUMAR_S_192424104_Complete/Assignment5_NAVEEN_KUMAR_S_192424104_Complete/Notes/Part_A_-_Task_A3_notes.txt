  ALGORITHM Settle(bill, payer)
  INPUT  : a Bill and a Payer (any derived kinds)
  OUTPUT : (covered, patientPays)
  BEGIN
    covered ← payer→AmountCovered(bill)      // late-bound; may THROW ClaimError
    patientPays ← bill→Total() − covered
    RETURN (covered, patientPays)
  END

Because both Bill and Payer are abstract, Settle works for every combination (4 bill
kinds × 3 payers = 12 combinations) without a single type test – a double use of
runtime polymorphism.

A3.2 – Extension (2 Marks)

A corporate tie-up is added by deriving a new class from Payer in a new file:

  CLASS CorporateTieUp DERIVED FROM Payer
    DATA: company, percent, perBillCap
    FUNCTION Name() RETURNS company
    FUNCTION AmountCovered(bill)
    BEGIN
        IF bill→Type() = "ER" THEN THROW ClaimError("tie-up excludes emergency bills")
  END IF
        RETURN MIN(bill→Total() × percent / 100, perBillCap)
    END
  END CLASS
